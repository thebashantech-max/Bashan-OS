# Bashan OS — Localization

13 shipped languages: English, Spanish, German, French, Portuguese,
Kurdish Kurmanji, Russian, Greek, Arabic, Hebrew, Syriac, Sorani, Persian.

All Bashan-specific strings (welcome app, installer additions, dock tooltips,
boot-song toggle) are translated into all 13.

## Known upstream gaps — re-verified against trixie, Stage 4

Checked by installation candidate inside the build container, not by name
lookup. Two Stage 1 assumptions turned out to be wrong and are corrected here.

| Language | LibreOffice UI | Spellcheck | Notes |
|---|---|---|---|
| English | yes | `hunspell-en-us` | |
| Spanish | `libreoffice-l10n-es` | `hunspell-es` | |
| German | `libreoffice-l10n-de` | `hunspell-de-de` | |
| French | `libreoffice-l10n-fr` | `hunspell-fr` | |
| Portuguese | `libreoffice-l10n-pt` | `hunspell-pt-pt`, `-pt-br` | |
| Russian | `libreoffice-l10n-ru` | `hunspell-ru` | |
| Greek | `libreoffice-l10n-el` | `hunspell-el` | |
| Arabic | `libreoffice-l10n-ar` | `hunspell-ar` | RTL |
| Hebrew | `libreoffice-l10n-he` | `hunspell-he` | RTL |
| **Persian** | `libreoffice-l10n-fa` | **`myspell-fa`** | RTL. **Correction:** Stage 1 recorded Persian as having no dictionary. It has one — as a myspell package, which LibreOffice reads via `dictionaries-common`. Persian gets both a translated UI and spellcheck. |
| **Kurmanji** | **none** | **none** | `libreoffice-l10n-ku` does not exist. **Correction:** `hunspell-ku` does not exist either — only `aspell-ku`, which LibreOffice does not use. So Kurmanji has no office spellcheck, not just no translated UI. Locale is `ku_TR` only. |
| **Sorani** | **none** | **none** | No UI translation, no dictionary of any kind. Weak upstream coverage overall. |
| **Syriac** | **none** | **none** | No UI translation, no dictionary of any kind. Weak upstream coverage overall. |

Kurmanji, Sorani and Syriac therefore get the **English** LibreOffice UI with
correct RTL handling and fonts, and the installer says so plainly.

Coverage of KDE and system strings beyond this table has **not** been verified
yet and must not be claimed. Stage 8 does the full pass.

## RTL

RTL languages: Arabic, Hebrew, Syriac, Sorani, Persian. These mirror the dock
(logo launcher moves to the right) and place the desktop trash icon bottom-left.
