# Bashan OS — Localization

13 shipped languages: English, Spanish, German, French, Portuguese,
Kurdish Kurmanji, Russian, Greek, Arabic, Hebrew, Syriac, Sorani, Persian.

All Bashan-specific strings (welcome app, installer additions, dock tooltips,
boot-song toggle) are translated into all 13.

## Known upstream gaps — verified at Stage 1

| Language | Gap | Handling |
|---|---|---|
| Kurmanji (ku) | No LibreOffice UI translation | Office UI defaults to English; correct RTL + fonts; stated in the installer |
| Sorani (ckb) | No LibreOffice UI translation; weak upstream coverage generally | Same as above; coverage flagged |
| Syriac (syr) | No LibreOffice UI translation; weak upstream coverage generally | Same as above; coverage flagged |
| Persian (fa) | No hunspell dictionary available | Noted to the user; spellcheck unavailable |
| Kurmanji | Locale exists only as `ku_TR` | Documented; no `ku_IQ`/`ku_SY` offered |

Coverage beyond this table has **not** been verified yet and must not be
claimed. Stage 8 does the full localization and RTL pass and updates this file
with measured results per language.

## RTL

RTL languages: Arabic, Hebrew, Syriac, Sorani, Persian. These mirror the dock
(logo launcher moves to the right) and place the desktop trash icon bottom-left.
